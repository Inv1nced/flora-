# Флора & Лепесток

Сайт цветочной мастерской на React, TypeScript и Vite.

Сайт: https://inv1nced.github.io/flora-/

## Локальный запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Проверка типов: `npm run lint`. Сборка: `npm run build`.

Изменения в `main` автоматически собираются и публикуются через GitHub Actions.

Каталог, фильтры, конструктор букета и корзина работают в браузере.
Оформление заказа пока демонстрационное: данные не отправляются в магазин, оплата не подключена.
